# Testing

| Suite                 | Location                           | Command               | Covers                                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------- | ---------------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Domain unit tests     | `packages/shared/src/**/*.test.ts` | `npm run test:shared` | Deadlines (boundaries, grace, DST, extensions, cutoffs), late penalties, lifecycle transitions, submission state machine, grading and rubric validation, reminders, password rules, schema validation and injection                                                                                                                                                                                                         |
| API unit tests        | `apps/api/src/lib/lib.test.ts`     | `npm run test:api`    | Environment validation, CSV escaping, ICS, encryption, filename and storage-key safety, log and audit redaction, backoff                                                                                                                                                                                                                                                                                                    |
| API integration tests | `apps/api/test/*.test.ts`          | `npm run test:api`    | Real HTTP through Express against an in-memory MongoDB replica set: authentication lifecycle, sessions and replay, CSRF, lockout, enumeration, assignments, submissions, uploads, grading, extensions, inbox, analytics, calendar, concurrency, invitations, rosters and CSV, administration, announcements, notifications, platform, worker jobs and outbox reliability, and all authorization and tenant-isolation checks |
| Web tests             | `apps/web/src/**/*.test.{ts,tsx}`  | `npm run test:web`    | Redirect safety, time-zone conversion, API client (CSRF, single-flight refresh, session expiry), form accessibility, guards, login errors, confirmation dialogs                                                                                                                                                                                                                                                             |
| End-to-end            | `apps/web/e2e/*.spec.ts`           | `npm run test:e2e`    | The 20 required journeys with real frontend, API, worker and database, plus axe WCAG 2.2 AA scans                                                                                                                                                                                                                                                                                                                           |

Isolation: each API test file uses its own database on a shared in-memory replica set; E2E starts a dedicated stack (`e2e/stack.ts`) on ports 4100 and 5174 with captured email. No test depends on external email, storage or cloud credentials.

## Required end-to-end scenarios

`apps/web/e2e/journey.spec.ts` titles reference the scenario numbers: invitation sign-up and sign-in (1–2), course creation and enrollment (3–4), creation and publication (5), the student sees the assignment, saves a draft and submits with a durable receipt (6–9), the teacher reviews, grades and publishes and the student sees the grade (10–13), worker-generated reminder (14), permission denial in UI and API (15), cross-organization isolation (16), logout and session end (17), a failed request never showing success (18), resubmission limits (19) and extension enforcement (20).
